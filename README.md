# Glowing Flower Animation

Glowing orange flowers that grow, bloom and release rising pollen, built with plain HTML and CSS plus a little JavaScript. It is `index.html` with `style.css` and `script.js`, and it works on desktop and mobile.

**[Live demo](https://rohithgoud30.github.io/glowing-flower/)** (press "Play" to start the sound)

![Preview](preview.gif)

## Run locally

```sh
npx serve
```

Then open http://localhost:3000.

## Files

- `index.html`: the page
- `script.js`: builds the flowers and runs the animation
- `style.css`: the styles
- `audio.mp3`: looping soundtrack
